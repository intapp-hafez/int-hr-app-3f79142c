# Employee-Related APIs & Methods

## Base URL

These are TanStack Start server functions, not REST endpoints, so they are invoked
through the framework's RPC layer rather than by a fixed external URL.

- **Development:** `http://localhost:8080`
- **Production / Preview:** `https://hr.company.com`
- **Published app:** configured project domain

Client calls go through `useServerFn(fn)`; the framework routes them to the correct
server function internally.

All endpoints are TanStack Start server functions (createServerFn), invoked from the client
via `useServerFn(fn)` or a direct call. Inputs pass as `{ data: ... }`. Auth-guarded
functions use `requireSupabaseAuth` or `requireAdminAccess` middleware.

## 1. Employees (admin CRUD & directory)
File: src/backend/functions/employees.functions.ts

- listEmployeesAdmin        POST   List/search employees with filters (dept, status,
                                   inactiveReason, contract, salary mode, etc.). Paginated.
- getEmployeeDetail         POST   Full profile for one employee (by id).
- createEmployeeAdmin       POST   Create a new employee + linked auth user.
- updateEmployeeAdmin       POST   Partial update of employee profile fields.
                                   Requires `inactive_reason` when status=Inactive.
- deleteEmployeeAdmin       POST   Delete a single employee.
- bulkDeleteEmployeesAdmin  POST   Delete multiple employees by id[].
- bulkSetEmployeeStatus     POST   Activate/Deactivate many employees at once
                                   (reason required when deactivating).
- listEmployeeStatusAudit   POST   Timeline of Active/Inactive changes for one employee.
- importEmployeesAdmin      POST   Bulk import from parsed Excel/CSV rows.
- sendEmployeeWelcomeEmail  POST   (Re)send onboarding email with credentials.
- listCitiesAndDistricts    GET    Reference lookups for address fields.
- listEmployeeDocuments     POST   List uploaded documents for an employee.
- uploadEmployeeDocument    POST   Upload a document (contract, ID, etc.).
- deleteEmployeeDocument    POST   Remove a document.
- getEmployeeAttendanceHistory POST Attendance rows for an employee within a range.
- getEmployeeLeavesHistory  POST   Leaves history for an employee.
- bulkAssignEmployeeRole    POST   Assign a role to many employees.
- adminTransferEmployee     POST   Transfer employee between departments/managers.

Client validation helpers (src/lib/employees.functions.ts):
- validateEmployeesBatch    POST   Zod validation for bulk import rows.
- validateRehire            POST   Prevents overlapping contracts on rehire.

## Calling pattern (client)

  import { useServerFn } from "@tanstack/react-start";
  import { updateEmployeeAdmin } from "@/backend/functions/employees.functions";

  const update = useServerFn(updateEmployeeAdmin);
  await update({ data: { id, patch: { status: "Inactive", inactive_reason: "Resigned" } } });

For queries prefer:
  useQuery({ queryKey: ["employee", id], queryFn: () => getEmployeeDetail({ data: { id } }) })

## FULL ENDPOINT LIST (server function name — HTTP method)
================================================================================

All server functions are invoked as same-origin POSTs to the TanStack RPC layer
(`/_serverFn/<hash>`). The "method" column below is the semantic method declared
in `createServerFn({ method })` — GET = pure read, POST = mutation/read-with-body.
Never `fetch` the RPC URL directly; call the exported function via `useServerFn`.
